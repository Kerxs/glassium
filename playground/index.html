Glassium

液态玻璃，画在网页里

下面这台 iPhone 和这台 Mac 的界面里，每一块玻璃都是 GPU 实时画的：边缘把背后的壁纸和照片弯过来， 色散、亮边、按下去的光，都跟着网页的 DOM 走。它们都能点。

Playground：调材质、拿代码 GitHub npm API 文档

iPhone

主屏幕的图标、小组件、Dock 都是清透的玻璃，壁纸是画进场景的 <glass-fill>。 边缘那一圈把壁纸上的圆环和条纹弯了过来 —— 这是真的折射，不是模糊。

  • 点「照片」：照片在玻璃标签栏底下滚动，按钮里的「选择」会分出水滴
  • 点右上角的电池：拉下控制中心，开关、滑块都能用
  • 按住任何一颗玻璃按钮：光从按下的地方亮起来

Mac

菜单栏上的控制中心按钮一按，变形成整块面板（morphGlass）；照片窗口的侧栏和工具栏浮在内容上， 横幅和照片从它们底下滚过去。Dock 是一整条玻璃。

  • 点菜单栏右边的按钮：控制中心从按钮里长出来，再点一下缩回去
  • 在窗口里滚动照片，或者点工具栏的「年 / 月 / 日」
  • 点窗口左上角的红点关掉它，再点 Dock 上的「照片」打开

玻璃折射的是 Glassium 自己画的场景（壁纸与照片都是画进场景的填充），不是它背后的网页 DOM —— 所以正文文字不会被折射。原理和限制见 limitations.md。 别的页面：Playground、性能测试、 逐项验证、调试台。
